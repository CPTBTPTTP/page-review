# 医疗健康行业惯例

审查医疗 / 健康类页面时，参照以下主流惯例（医院挂号 / 在线问诊 / 健康管理类 App）判断"该有的有没有、交互合不合惯例"。

## 预约挂号
- 应有科室 / 医生选择、号源（日期 + 时段）、余号 / 已满状态。
- 就诊人选择（可切换 / 新增就诊人）。
- 挂号须知、费用说明。

## 病历 / 就诊记录
- 病历应有：主诉、诊断、处方、医嘱。
- 就诊记录时间线（挂号 / 就诊 / 缴费 / 取药）。

## 处方 / 用药
- 处方应有药品名称、剂量、用法用量、医嘱。
- 用药提醒应有频次、时间。

## 报告 / 检查
- 检查报告应有指标、参考范围、异常标记。
- 历史报告可对比、有趋势说明。

## 在线问诊
- 问诊应有医生资质展示、问诊费用、服务说明。
- 快捷问题点击后直接发送。

## 合规（医疗行业特有，敏感场景必审）
- 患者隐私脱敏（姓名、身份证、病历内容）。
- 病历 / 报告访问需授权。
- 涉及诊断 / 处方内容需符合医疗合规要求，不得夸大疗效。
- 危急情况应有紧急就医引导。
- 敏感数据（病历、处方）展示与传输需脱敏或授权，访问记录可审计。
