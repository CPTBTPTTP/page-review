# 电商行业惯例

审查电商类页面时，参照以下主流惯例（淘宝 / 京东 / 拼多多 / 美团）判断"该有的有没有、交互合不合惯例"。

## 商品 / 服务列表
- 商品卡片应有：商品图、名称、价格、划线价（原价）、销量 / 好评率。
- 分类 / 二级分类点击应跳转到对应列表或搜索结果，而非仅 toast。

## 商品详情
- 价格区应有划线价与促销标签（限时特惠 / 满减）。
- 应有销量数据与评价星级（评分 + 评价条数）。
- 规格应支持真实 SKU 选择（选中后价格 / 库存联动）。
- 应有关键信息：规格参数、配送 / 服务说明、售后保障。

## 购物车
- 应有店铺分组、商品勾选（单选 / 全选）、失效商品处理区、合计与结算栏、多选删除。

## 确认订单 / 结算
- 应有优惠券选择、发票、订单备注、商品规格展示、预计送达时间。

## 订单
- 订单卡片应区分类型（商品 / 服务），有金额明细（优惠、运费）可展开。
- 待支付应显示倒计时。

## 支付
- 应有支付方式选择（余额 / 微信 / 支付宝等），非单一方式。
- 应有支付倒计时与支付协议勾选。

## 优惠券 / 促销
- 优惠券应有状态 Tab（未使用 / 已使用 / 已过期）。

## 门店 / 服务
- 门店列表应有距离排序、评分。
- 门店详情应有地址导航、电话、营业时间、评价。
- 服务预约应支持日期选择、服务对象（宠物 / 人）切换、价格展示。

## 客服
- 快捷问题点击后直接发送。
- 店铺客服与平台客服身份边界清晰。
