# 宠物行业惯例

审查宠物类页面时，参照以下主流惯例（波奇宠物 / 宠物家 / 小佩等）判断"该有的有没有、交互合不合惯例"。

## 宠物档案
- 档案应有：身份码 / 芯片号、品种、性别、生日 / 年龄、体重、绝育状态。
- 应有健康档案入口：免疫 / 驱虫 / 就诊记录。
- 应有编辑入口。

## 我的宠物 / 宠物列表
- 宠物卡片应有：头像、名字、品种、关键提醒（下次免疫 / 驱虫时间）。
- 应有"添加宠物"入口（扫码绑定 / 手动建档）。
- 应有待办提醒直达入口。

## 记日常 / 记录
- 记录应有分类（喂食 / 体重 / 洗澡 / 驱虫 / 就诊等），分类图标可直观识别。
- 花费记录应有分类（主粮 / 零食 / 医疗 / 用品等）。

## 记病例 / 症状
- 症状多选应直观可理解（图标 + 中文标签）。
- 高风险症状应有紧急就医引导。

## 血缘 / 族谱
- 血统 / 族谱展示应基于真实关系数据，避免随机占位。

## 宠物百科 / 能不能吃
- 百科应有足够品种数据量。
- "能不能吃"应有足够食物数据量，搜索应有联想。

## 服务预约（宠物洗护 / 美容 / 医疗）
- 预约应支持选择宠物（可切换）、选择日期时间、展示价格。
- 医疗预约应有医生 / 科室选择。

## 合规（宠物行业特有）
- 涉及疫苗 / 用药 / 诊疗内容需符合动物诊疗相关规范。
- 身份码 / 芯片号展示注意隐私边界。
